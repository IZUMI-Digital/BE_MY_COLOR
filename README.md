# BE MY COLOR - 色覚多様性向けユーザ補助アプリ

## BE MY COLORとは

Windowsで動作する、色覚多様性(色盲、色弱)のユーザを補助するアプリです。

画面に小さなアプリウィンドウが開き、マウスカーソル付近にある画素の中で比較的多い色の色名が表示されます。
ユーザは、画面に表示されている色が何色なのかを確かめることができます。
色名だけでなく、色のRGB値も表示されます。

## 動作環境

Windows11にて動作確認しています。

ソースコードからのビルドは、Visual Studio Community(2026)を用いて確認しています。

## 使用方法

ソースコードをビルドする、もしくはこのrepoのreleasesフォルダにあるexeファイルを取得し、実行します。

実行すると、画面に小さいアプリウィンドウが表示されます。
アプリウィンドウには、マウスカーソル付近にある画素の中で、1番多い色の色名が1段目に、2番目に多い色の色名が2段目に表示されます。
マウスカーソルを動かすと色名が更新されますので、画面上の知りたい色のある箇所にマウスカーソルを移動させてください。

1番目だけでなく2番目の色の色名も表示している理由は、文字の色を知りたい場合に、背景色が付近で1番多い色になってしまいがちなことへの考慮です。

色のRGB値は、グラデーションなど色が微妙に変化している場合には、それらの画素のRGB値の平均を表示しています。

アプリウィンドウ上部にある4個のボタンは、左から順に以下の動作をします。

* アプリウィンドウを最前面に表示する
* アプリウィンドウを最背面に表示する
* アプリウィンドウを最小化(アイコン化)する
* アプリを終了する

## ソースコードからのビルド方法

* Visual Studioにて、新しいプロジェクトを「Windowsデスクトップアプリケーション」として作成する
* プロジェクトのソースコードのウィンドウに、このrepoのsrcフォルダにあるmain.cppを貼り付ける
* ビルドする

## アプリの動作のカスタマイズ方法

main.cppの先頭付近で定義されている以下の定数の値を変更することで、アプリの挙動を調整できます。

* SAMPLE_N
    * マウスカーソル付近にある画素としてカウントする範囲(縦横SAMPLE_N×SAMPLE_N画素の四角形)
* TIMER_INTERVAL_MS
    * マウスカーソル付近にある画素の色情報を更新する間隔(単位はミリ秒)
* MIN_GROUP_SHARE
    * マウスカーソル付近にある画素で、色名をカウントする対象の下限を調整する
    * SAMPLE_N×SAMPLE_N画素の全画素数に対する割合(%)で指定する
    * 多数の色が散らばっている箇所でたまたま比較的画素数が多い画素の色名が表示されてしまうことを防ぐのが目的である
* WINDOW_WIDTH, WINDOW_HEIGHT
    * アプリウィンドウを表示する大きさ(画素数)
* WINDOW_PADDING
    * アプリウィンドウの余白(画素数)

## 補足

### 表示される色名について

色名の判定ロジックは、簡易的です。
HSL色空間での簡易的な色分類を用いており、厳密な色名というわけではありません。

作者自身が色覚多様性の当事者であるため、表示される色名が正常な色覚の人の感覚に合っているかは分かりません。
